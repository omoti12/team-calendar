# 現場管理

現場名ごとにチェックリスト（日にち・完了/未完了・備考）を管理するシンプルな Web アプリです。

## 使い方

公開URL: https://omoti12.github.io/team-calendar/

`index.html` をブラウザで開くだけでも動きます。

### GitHub Pages の設定（最初の1回だけ）

リポジトリの **Settings → Pages** で
- Source: **Deploy from a branch**
- Branch: **ccr-65599146-afoday** / **(root)** → Save

以降はこのブランチに push すると自動で公開ページが更新されます。

- **現場を追加**: 項目セット（さいたま市・川口市・東京都・なし）を選び、現場名を入力して「＋ 追加」
- **一覧**: 現場ごとにフォルダ（タブに完了/未完了/警告）で並ぶ。進み具合・完了/未完了・次にやる項目が見える
- **検索**: 上の検索欄に現場名の一部を入力
- **絞り込み**: 「未完了あり」「すべて完了」
- **現場の中身**: 初期項目（下記）が入った表。期限・台数/人数・完了日・状態（タップで完了/未完了切替）・備考を記入。完了にすると完了日に今日の日付が入る（変更可）
- **工事実行日**: 現場名のすぐ下に入力。一覧にも表示される
- **期限の警告**: 期限の1週間前になっても未完了の項目は赤＋⚠️で表示（期限切れも同様）。一覧でも警告のある現場が上に赤で出る
- **項目を追加**: 「＋ 項目を追加」で自由に行を追加。項目名は後から書き換え可能
- **保存 / 一覧に戻る**: 画面下のボタンで。入力は自動でも保存される
- **メモ**: 現場ごとの自由記入欄
- **メニュー（⋯）**: データの書き出し／読み込み（JSON）、印刷

### 項目セット

現場を作る時に地域ごとのセットを選ぶと、その項目が入った状態で作られる（`app.js` の `TEMPLATES`）。

- **さいたま市**: 申請・日程決め / ダンプ / カッター / 警備 / 道路占用 受取 / 道路使用 提出 / PR / 道路使用 受取 / 事前打合せ / メーター受取
- **川口市**: 事前打合せ / 預かり / 申請 / 道路使用 受取 / 道路使用 提出 / 道路使用 受取 / 日程決め / PR / ダンプ / 警備 / カッター
- **東京都**: 申請 / 道路占用 受取 / 日程決め / ダンプ / 警備 / カッター / 道路使用 提出 / 道路使用 受取 / PR
- **なし**: 空のまま作り、自分で項目を追加

## ホーム画面に追加（PWA）

公開URLをスマホで開き、メニュー（⋯）の「ホーム画面に追加」から追加できます。
アイコンから全画面で開け、電波がない場所でも使えます（ネットにつながっている時は常に最新版を読み込みます）。

- iPhone は Safari の共有ボタン →「ホーム画面に追加」。Safari とホーム画面のアプリはデータが別々になるので、追加したらアプリの方で使ってください。

更新するときは `index.html` と `sw.js` のバージョン番号（`?v=` と `CACHE`）を合わせて上げてください。

## チームで共有（クラウド）

最初に開くと合言葉を聞かれる。同じ合言葉を入れた人どうしで、同じ現場データをリアルタイムに共有する（Firebase Firestore）。

- データは `teams/{合言葉のSHA-256}/sites/{現場ID}` に保存。合言葉そのものは保存・送信しない
- セキュリティルールは `firestore.rules`（チーム一覧は取得できないので、合言葉を知らないと読み書きできない）
- 電波がない時は端末に保存し、つながった時に送信
- 合言葉を入れた時、その端末に残っている現場をチームに移すか聞く
- メニューの「合言葉を入れ直す」で別のチームに切り替え

## 注意（旧・仮版）

クラウドが使えない環境（`index.html` を直接開いた時など）では、今まで通り端末のブラウザ内（localStorage）に保存されます。
