# 現場管理

現場名ごとにチェックリスト（日にち・完了/未完了・備考）を管理するシンプルな Web アプリです。

## 使い方

公開URL: https://omoti12.github.io/team-calendar/

`index.html` をブラウザで開くだけでも動きます。

### GitHub Pages の設定（最初の1回だけ）

リポジトリの **Settings → Pages** で
- Source: **Deploy from a branch**
- Branch: **ccr-65599146-afoday** / **(root)** → Save

以降はこのブランチに push すると自動で公開ページが更新されます。

- **現場を追加**: 一覧の点線フォルダに現場名を入力して「フォルダを作成」
- **一覧**: 現場ごとにフォルダ表示（未完了は黄色、すべて完了で緑）。進み具合と次にやる項目が見える
- **検索**: 上の検索欄に現場名の一部を入力
- **絞り込み**: 「未完了あり」「すべて完了」
- **現場の中身**: 初期項目（下記）が入った表。日にち・状態（タップで完了/未完了切替）・備考を記入
- **項目を追加**: 「＋ 項目を追加」で自由に行を追加。項目名は後から書き換え可能
- **メモ**: 現場ごとの自由記入欄
- **メニュー（⋯）**: データの書き出し／読み込み（JSON）、印刷

### 初期項目

1. 申請・施工日日程決め（カッター・ダンプ・ケイビ）
2. 道路占用 受取り
3. 道路使用 提出
4. 道路使用 受取り
5. PR
6. 事前打合せ（施工日前日）
7. 組合にメーター取りに行く

## 注意（仮版）

データは使っている端末のブラウザ内（localStorage）に保存されます。
別の端末・別の人とは共有されません。共有が必要になったらサーバー/DB 対応を追加予定です。
